# 📷 Camera

Just a simple, private, offline camera application

<div align="left">
<br>

* I made this with Gemini 3 Pro because the Windows Camera app wasn't recording videos for some reason. 
* This app starts and stops recording instantly, has an audio recorder feature as well, and a gallery.
* Everything is saved in your browser storage.
* Tested on a Chromium browser (Brave).
* Opens in web app mode.
* This does NOT send any data anywhere; it is contained completely in your browser and can be run offline.

## ✨ Features

* Photo
* Video
* Audio
* Gallery
* Zoom, exposure, and structure
* Mirror/Normal
* Basic photo editor (brightness, contrast, saturation, structure, mirror/normal)
* Audio editor (loudness normalization, voice changer effects, auto trim, delete manual segments, undo/redo)
* Delete
* Selective delete

## 📄 Instructions

* Download the latest Camera.zip from the Releases tab.
* Ensure all of the files are extracted and contained within a single directory.
* Run CameraLauncher.exe

A browser window should open, and you'll be all set!
